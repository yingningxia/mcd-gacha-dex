# 麦麦图鉴 · MCD-GACHA-DEX

> 把麦当劳真实菜单变成可收集的麦门开卡图鉴，并用你自己的订单反向算出「你最爱吃什么」。
> 麦当劳程序员节创意开发大赛参赛作品（非官方产品）。

---

## 它解决什么

市面上的麦当劳工具都在做同一件事：**列菜单、算最省、推券**——这是信息搬运。
麦麦图鉴换了个角度：

- **吃麦当劳也能养成。** 真实菜单就是卡池，每道菜按真实价格+标签定稀有度（N/R/SR/SSR）。**抽卡券模型**：每天 1 张免费抽 + 下单任意价格 +1 券 + 转发好友 +1 券；稀有度概率重平衡（N 60% / R 25% / SR 12% / SSR 3%）。抽到没吃过的就解锁图鉴格。**麦门开卡动画**：金拱门中央一条拉链，从上往下滑 → 推门（金拱门）→ 门后金光闪过 → 现身抽中的产品。不同等级卡**下单满 3/5/7/10 次自动点亮 💡**，点亮的卡可自由组合成**专属套餐**并一键下单；**刚抽中的卡也能现搭**——开卡页内嵌「用抽中的卡定制专属套餐」构建器，勾选抽中卡、给每张填定制需求（默认带上次的选择）、起个套餐名，一键生成下单/收藏指令。个性化需求直接标在产品卡上、点单默认带上次选择。抽到的卡/套餐都可以一键下单，把游戏落回真实点餐。
- **你到底最爱吃什么？（麦门最爱）** 基于你真实的订单，算出**本周/本月/全部**你最爱点的单品或套餐、最爱在什么时候吃、最爱什么口味，排出「最爱榜」。**榜一**带「一键复刻」按钮；整页带俏皮话/梗，并支持**一键保存成图片**分享。卡面一律用**真实产品图**（LIVE 读麦当劳 MCP 原图）加金属徽章质感；无真实图时用**分类食物插画徽章**兜底——有图不是字，**不用 emoji**，UI 含金拱门元素。

趣味向，但踩在真实数据上：图鉴来自 `query-meals`，订单与下单来自 `order-list` / `create-order`，价格来自 `calculate-price`。

## 安装

1. 申请麦当劳 MCP Token：打开 https://open.mcd.cn/mcp → 登录 → 控制台 → 激活 → 复制 Token。
2. 在 WorkBuddy 的「连接器」中配置 `mcd-mcp`：
   ```json
   {
     "mcpServers": {
       "mcd-mcp": {
         "type": "streamableHttp",
         "url": "https://mcp.mcd.cn",
         "headers": { "Authorization": "Bearer 你的_TOKEN" }
       }
     }
   }
   ```
3. 安装本 Skill（导入 `mcd-gacha-dex` 目录或仓库）。
4. **没有 Token 也能跑**：自动进入 DEMO 模式，用内置离线数据集演示完整流程。

## 使用

直接用自然语言对 WorkBuddy 说：

| 你想做 | 说一句 |
|---|---|
| 麦门开卡 | 「来一张麦门开卡」「今天吃什么盲盒」「我还有几张抽卡券」 |
| 看收集/点亮 | 「我的图鉴收集多少了」「哪些卡点亮了」 |
| 套餐工坊 | 「把 巨无霸+大薯条+可乐 存成套餐叫『快乐水套餐』」 |
| 记住口味 | 「记住：巨无霸 不要酸黄瓜」 |
| 看成就 | 「我解锁了哪些成就」 |
| 看最爱/麦门最爱 | 「我本月最爱吃什么」「本周最爱」「我的麦门最爱」 |
| 复刻最爱 | 点图鉴卡里的「一键复刻」，或说「把最爱榜一下单」 |
| 出图鉴卡/存图 | 「给我生成麦麦图鉴」「生成我的麦门最爱卡片」（可一键存图） |
